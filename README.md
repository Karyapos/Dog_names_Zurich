# Dog Names Trend Analysis - Zurich

**Tools Used:**  
SQL (PostgreSQL), Power BI

**Skills Applied:**  
Data cleaning, trend analysis, SQL querying, data visualization

---

### 🔍 Project Overview

In this project, I analyzed a dataset of dog names over the years to identify naming trends and popular name variations. The dataset was sourced from the **City of Zurich's Open Data Portal**. The goal was to practice SQL querying and explore insights via data visualization.

---

### 🛠️ Key Tasks

- Cleaned and filtered the data to focus on popular names and gender-specific trends.
- Created SQL queries for data analysis, uncovering key patterns and name trends.
- Visualized findings using only SQL for starters to highlight the most popular names and significant trends.

### 📌 Key Insights

- **Diverse Naming Trends:** The leading name, *Coco*, accounts for only **2%** of the total dog names, showing a diverse spread of unique names.
- **Consistent Gender Distribution:** Naming trends, whether masculine, feminine, or unisex, have remained largely consistent from 1994 to 2024.
- **Large Dataset:** The analysis covered **9,853 distinct names** across **70,000+ dog registrations**.

### **Conclusion & Future Plans**

This project allowed me to apply SQL, clean data, and create visualizations to derive actionable insights. Moving forward, I aim to take on more complex datasets and improve my predictive analytics skills.
